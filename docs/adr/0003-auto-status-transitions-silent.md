# Silent automatic WatchStatus transitions with audit trail

WatchStatus transitions driven by EpisodeWatch history (`watching` to `completed` when all cached episodes are watched; `watching` to `paused` after 30 days of inactivity) happen silently: no modal, no toast, no notification. Every transition, automatic or manual, writes a `StatusTransition` row that surfaces in the user's activity feed. The trade-off was against showing a confirmation dialog at the moment of an auto-transition, and against keeping transitions entirely manual. Confirmation dialogs interrupt the user during the very action that triggered the transition (marking an episode) and feel paternalistic; manual-only transitions mean the user has to remember to update their status, which is exactly the friction the auto-transitions exist to remove. The audit trail via `StatusTransition` preserves user agency: nothing is hidden, the change is reversible, and the history is browsable. The cost is that a user who does not check the activity feed may not notice that an entry was auto-completed; we accept this because the alternative (interrupting the user) is worse.
